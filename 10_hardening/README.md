## What is hardening?

Hardening is a systematic approach to enhance security, reduce attack surfaces, removing unnecessary stuffs and setup access control and monitoring tools. A hardened system is restricted to only the essentials, which limits exploitation and available attack vectors. An attack vector is a specific path or entry point to gain unauthorized access to an IT system.

### Principles 

- principle of least privilege - user has enough access to do their job and not more
- mulitple layer of security
